# Perfiles de proyecto

Los perfiles adaptan AES Core al tipo de producto y stack. No reemplazan AES Core ni reducen sus controles fundamentales.

Cree `project-profile.md` usando `project-profile.template.md`. Puede añadir perfiles especializados (web, backend, móvil, escritorio, embedded, data) cuando se conozcan los requisitos concretos.

No se incluye un perfil de stack prescriptivo en AES 1.0.0: la tecnología debe elegirse para cada proyecto y documentarse con sus comandos, rutas protegidas y estándares de calidad.
